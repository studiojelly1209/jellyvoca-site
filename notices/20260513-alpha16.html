🆕 alpha.16 업데이트 안내

2026년 5월 13일 · v1.0.0-alpha.16

🇰🇷 한국어

💬 상황별 회화 — 신규 기능

  • 카페, 레스토랑, 공항, 호텔, 쇼핑, 병원·약국, 교통, 비즈니스 8개 상황의 실전 영어 표현을 학습할 수 있습니다.
  • 각 상황은 세부 주제로 나뉘며, 표현마다 한글 번역과 💡 사용 팁이 함께 제공됩니다.
  • FREE 유저: 광고 시청 또는 50코인으로 주제 해금 → 24시간 동안 자유롭게 재열람 가능. 남은 시간도 실시간으로 표시됩니다.
  • PRO 유저: 모든 주제 무제한 열람

🏠 홈화면 개편

  • 학습 버튼이 2열 그리드 형태로 재구성되었습니다.
  • 오늘의 학습 · 추가 학습 · 복습하기 · 약점 복습 · 상황별 회화를 한눈에 확인할 수 있습니다.

🔄 복습 기능 개선

  • 복습 흐름 개선: 1차 복습은 4지선다 객관식 퀴즈(3라운드), 2·3차 복습은 예문 학습(1라운드)으로 진행됩니다.
  • 복습 자동 넘김 시간이 10초 → 30초로 변경되었습니다.
  • 추가 학습 완료 후 해당 단어로 복습 알림이 자동 예약됩니다.

🐛 버그 수정

  • 다크모드에서 객관식 보기 글씨가 보이지 않던 문제를 수정했습니다.
  • 글로벌 도전 코인 결제 후 반응 없던 문제를 수정했습니다.
  • 친구 초대 코드 복사와 전체 메시지 공유 기능이 분리되었습니다.
  • PRO 구독 구매 시 앱 재시작 없이 즉시 반영됩니다.

🇺🇸 English

💬 Situational Conversation — New Feature

  • Learn real-world English phrases across 8 situations: Cafe, Restaurant, Airport, Hotel, Shopping, Hospital & Pharmacy, Transportation, and Business.
  • Each situation is divided into sub-topics, with Korean translations and 💡 usage tips for every phrase.
  • FREE users: Unlock a topic by watching an ad or spending 50 coins — access lasts 24 hours, with a countdown timer shown on each topic.
  • PRO users: Unlimited access to all topics.

🏠 Home Screen Redesign

  • Learning buttons are now arranged in a 2-column grid for easier navigation.
  • Today's Learning, Extra Learning, Review, Weak Review, and Situational Conversation are all visible at a glance.

🔄 Review Improvements

  • Updated review flow: 1st review is a multiple-choice quiz (3 rounds); 2nd & 3rd reviews are example-based (1 round each).
  • Auto-advance timer in review extended from 10s → 30 seconds.
  • Extra learning now automatically schedules a follow-up review session.

🐛 Bug Fixes

  • Fixed multiple-choice text not visible in dark mode.
  • Fixed global challenge coin payment with no response.
  • Separated invite code copy from full message share.
  • PRO subscription now applies immediately without restarting the app.
