beta.3 업데이트 안내

2026년 6월 13일 · v1.0.0-beta.3

한국어

로그인 유지 안정성 개선

  • 앱을 다시 실행하거나 백그라운드에서 돌아왔을 때 로그인 상태가 더 안정적으로 복원되도록 개선했습니다.
  • 기존 계정과 학습 데이터 흐름은 그대로 유지하면서, 불필요하게 로그인 화면으로 돌아가는 상황을 줄였습니다.

개인화 복습 알림

  • 복습 알림 문구가 더 구체적으로 바뀌었습니다.
  • 오답 기록이 있는 단어가 있으면 헷갈린 단어를 먼저 알려주고, 마스터 전 단어가 있으면 다시 확인할 수 있도록 안내합니다.

앱 경량화와 안정화

  • 앱에 포함되는 미사용 이미지 자산을 정리해 설치 파일과 웹 자산 크기를 줄였습니다.
  • Remote Config 호출 간격을 정식 빌드에 맞게 조정해 앱 시작 시 불필요한 네트워크 요청을 줄였습니다.
  • 정식 출시 전 안정성을 높이기 위한 내부 점검과 빌드 메타데이터 정리를 함께 반영했습니다.

English

Improved Login Persistence

  • Login sessions are now restored more reliably after restarting the app or returning from the background.
  • The existing account and learning data flow remains unchanged, while unexpected returns to the login screen should happen less often.

Personalized Review Notifications

  • Review notifications now provide more specific messages.
  • If you have words with wrong-answer history, the notification highlights them first. If there are words not yet mastered, it guides you back to review.

Lighter App Assets and Stability Updates

  • Unused image assets were removed from the app bundle to reduce packaged web assets.
  • Remote Config fetch timing was adjusted for production builds to reduce unnecessary startup network requests.
  • Additional internal checks and build metadata updates were applied ahead of the official release.
