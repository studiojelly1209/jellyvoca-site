젤리 영단어 1.0.0 정식 출시 안내

2026년 6월 22일 · v1.0.0

한국어

정식 출시 안내

젤리 영단어가 alpha와 beta 테스트를 마치고 1.0.0 정식 버전으로 출시됩니다. 테스트 기간 동안 보내주신 의견을 바탕으로 학습 흐름, 로그인 안정성, 복습 알림, 랭킹, 결제와 광고 경험을 차근차근 다듬었습니다.

처음부터 큰 학습량을 강요하기보다, 매일 부담 없이 이어갈 수 있는 작은 루틴을 만드는 것이 젤리 영단어의 목표입니다. 정식 버전에서도 하루 5단어 학습을 중심으로 복습, 약점 관리, 보상, 랭킹이 자연스럽게 이어지도록 구성했습니다.

테스트 피드백으로 개선한 부분

  • 앱을 다시 실행해도 로그인 상태가 안정적으로 유지되도록 개선했습니다.
  • 학습 후 다시 봐야 할 단어를 놓치지 않도록 복습 알림 흐름을 정리했습니다.
  • 처음 사용하는 사용자도 홈 화면과 학습 기능을 더 쉽게 찾을 수 있도록 화면 구성을 다듬었습니다.
  • 랭킹, 코인, 선물함, PRO 기능의 동작과 예외 상황을 점검했습니다.
  • 정식 출시 전 테스트 데이터 정리와 운영 환경 점검을 완료했습니다.

앞으로의 운영 방향

  • 단어와 예문 품질을 계속 보완하고, 학습 데이터를 바탕으로 복습 경험을 더 자연스럽게 개선하겠습니다.
  • 사용자 피드백은 정식 출시 이후에도 계속 반영하겠습니다.
  • 문의가 필요한 경우 공식 도움말 페이지의 연락처로 알려 주세요.

English

Official Release

Jelly Voca is officially launching as version 1.0.0 after its alpha and beta test periods. Based on feedback from testers, we refined the learning flow, sign-in stability, review reminders, rankings, payments, and ad experience.

The goal of Jelly Voca is not to overwhelm learners with a large amount of study at once. It is built around a small daily habit, with five words a day connected to review, weak-point practice, rewards, and rankings.

Improved Through Testing

  • Sign-in persistence has been improved so the app can keep users logged in more reliably.
  • Review reminder flow has been refined to help learners return to words they may forget.
  • The home screen and learning features have been adjusted for easier first-time use.
  • Rankings, coins, gifts, and PRO features have been reviewed for launch readiness.
  • Test data cleanup and production environment checks have been completed before release.

What Comes Next

  • We will continue improving vocabulary content, example sentences, and the review experience.
  • User feedback will continue to guide updates after the official launch.
  • For support, please use the contact information listed on the official help page.
