🆕 alpha.17 업데이트 안내

2026년 5월 14일 · v1.0.0-alpha.17

🇰🇷 한국어

📚 TOEIC 단어 500개 추가

  • 실용 비즈니스·업무 어휘 500개가 새롭게 추가되었습니다. 기존 단어와 중복 없이 선별된 단어들입니다.
  • 모든 신규 단어에 영어 예문과 한글 번역이 함께 제공됩니다.
  • PRO 유저: 즉시 학습 가능 (오늘의 학습, 복습 포함).
  • FREE 유저: PRO 업그레이드 후 이용 가능.

💬 상황별 회화 주제 확장

  • 카페, 레스토랑, 공항, 호텔, 쇼핑, 병원·약국, 교통, 비즈니스 각 카테고리에 주제 2개씩(총 16개)가 추가되었습니다.
  • 주제별 예문이 풍부해져 더 다양한 실전 표현을 학습할 수 있습니다.

🏆 랭킹 개선

  • 연속 출석 랭킹 전체 탭이 현재 연속일 대신 역대 최고 연속 출석 기록을 기준으로 변경되었습니다.
  • 꾸준히 쌓아온 최고 기록이 영구적으로 유지됩니다.

🐛 버그 수정

  • 안드로이드 하드웨어 뒤로가기 버튼 사용 시 의도치 않게 앱이 종료되던 문제를 수정했습니다.
  • 관리자 페이지 단어 통계 수치가 실제와 다르게 표시되던 문제를 수정했습니다.
  • 계정 삭제 후 동일 아이디 재생성이 불가했던 문제를 수정했습니다.
  • 비활성화된 유저를 관리자 화면에서 확인하고 삭제할 수 있도록 개선했습니다.

  • Fixed an issue where a deleted account could not be re-created with the same username.
  • Admins can now view deactivated users and permanently delete in-app accounts.
