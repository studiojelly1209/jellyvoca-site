사용 방법 가이드

젤리 영단어 v1.0 기준

시작하기

1

회원가입

앱 설치 후 아이디(영문+숫자)와 비밀번호를 입력해 계정을 만드세요. 닉네임은 나중에 프로필에서 설정할 수 있습니다.

2

단어장 선택

일반 · 수능 · 토익 · 학술 중 원하는 카테고리를 선택하세요. 첫 화면에서 오늘의 학습 단어 5개가 제시됩니다.

3

학습 시작

홈 화면의 오늘 학습 시작 버튼을 누르면 단어 카드가 나타납니다. 뜻을 맞히면 코인과 함께 다음 단어로 넘어갑니다.

학습 방식

📖 오늘의 학습 (기본 5단어)

매일 새로운 단어 5개가 제공됩니다. 단어 카드를 보고 뜻을 선택하거나 스크롤하여 예문을 확인하세요.

🔁 복습

이전에 학습한 단어를 다시 풀어볼 수 있습니다. 복습은 기억을 강화하는 가장 효과적인 방법입니다.

➕ 추가 학습

오늘의 5단어를 모두 완료하면 추가 학습(+5단어) 버튼이 활성화됩니다. 코인 50개를 사용해 더 많은 단어를 학습할 수 있습니다.

💡 매일 꾸준히 학습하면 주간 랭킹에서 좋은 순위를 유지할 수 있어요!

💛 코인 시스템

코인 획득 방법

  • 오늘의 학습 완료: +10코인 (PRO: +15코인)
  • 추가 학습 완료: +5코인 (PRO: +8코인)
  • 복습 완료: +5코인 (PRO: +8코인)
  • 주간 랭킹 보상: 1위 30 · 2위 20 · 3위 10코인 (PRO +50%)
  • 친구 초대 보상
  • 관리자 특별 지급

코인 사용 방법

  • 코인 상점에서 프로필 아이템(아바타·배경·뱃지) 구매
  • 추가 학습 활성화 (-50코인)

코인 내역 확인

홈 화면 상단의 💛 코인 배지를 누르면 획득·사용 내역을 확인할 수 있습니다.

🎁 선물함

코인 보상, 배지, 친구 초대 보상 등 모든 보상은 선물함을 통해 수령합니다. 미수령 선물이 있으면 홈 화면에 빨간 점이 표시됩니다.

  • 퀘스트 위의 🎁 선물함 버튼을 누르세요.
  • 수령하지 않은 선물을 탭하면 즉시 코인·배지가 지급됩니다.
  • 수령 완료한 선물도 기록으로 남아 확인할 수 있습니다.

🏆 랭킹

주간 학습량 랭킹

이번 주 학습한 단어 수로 순위가 결정됩니다. 매주 월요일 초기화되며, 상위 3명에게 코인이 지급됩니다.

누적 정답률 랭킹

전체 누적 정답률 기준 랭킹입니다. 학습 단어가 100개 이상인 사용자만 표시됩니다.

랭킹전

심화 단어(랭킹전 전용)로 실력을 겨루는 특별 모드입니다. 랭킹전 단어는 일반 학습과 별도로 관리됩니다.

👤 프로필 꾸미기

코인으로 구매한 아바타, 배경, 뱃지로 나만의 프로필을 꾸밀 수 있습니다.

  • 프로필 화면에서 아이템을 선택·장착하세요.
  • 미리보기를 통해 적용 전 모습을 확인할 수 있습니다.
  • 랭킹 화면에서 다른 유저의 프로필도 확인할 수 있습니다.

👫 친구 초대

초대 링크를 공유하면 친구가 가입할 때 나와 친구 모두 코인을 받습니다.

  • 홈 화면 → 초대 버튼 → 링크 공유
  • 보상은 친구 가입 후 선물함으로 자동 지급됩니다.

⭐ PRO 구독

PRO 구독 시 광고 제거 및 아래 혜택이 제공됩니다.

  • 🎁 첫 구매 축하 코인 1,000개 즉시 선물함 지급
  • 일일 학습 20단어 (FREE: 5단어)
  • 추가 학습 광고 없이 무료 +5단어
  • 코인 획득량 +50% 보너스 (학습·복습·랭킹 보상 모두 적용)
  • 전체 10,000개+ 단어 이용
  • 오답 단어만 골라 집중 학습
  • PRO 전용 코인 상점 아이템
  • 광고 완전 제거
