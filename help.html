1. 주요 기능

📚 매일 단어 학습

FREE는 하루 5단어, PRO는 하루 20단어를 학습합니다. 각 단어는 3라운드 반복으로 기억을 강화합니다.

➕ 추가 학습

기본 학습 완료 후 추가 5단어를 더 학습할 수 있습니다. FREE는 광고 시청 또는 50코인, PRO는 광고 없이 무료입니다.

🔁 복습 / 🎯 약점 복습

배운 단어를 다시 풀 수 있고, PRO는 틀린 단어 위주의 맞춤 복습을 하루 1회 이용할 수 있습니다.

🎁 선물함 / 💛 코인 내역

랭킹 보상, 친구 초대, PRO 첫 구독 혜택은 선물함에서 수령합니다. 홈 화면 코인 배지를 누르면 현재 잔액과 코인 내역을 볼 수 있습니다.

⚔️ 랭킹전 / 🏆 학습 랭킹

주간 학습량 랭킹과 글로벌 도전(랭킹전)으로 다른 사용자와 경쟁할 수 있습니다.

3. 정책 및 데이터 안내

  • 1인 1계정 정책: 계정 공유, PRO 공유·양도는 금지됩니다.
  • 데이터 저장: 학습 진도, 즐겨찾기, 오답 기록, 선물함 등은 Firebase 클라우드에 저장됩니다.
  • 기기 변경: 새 기기에서 로그인하면 기존 데이터가 복원됩니다.
  • 계정 삭제: 앱 설정에서 계정 및 학습 데이터를 영구 삭제할 수 있습니다.
  • 광고 / 결제: FREE는 AdMob 광고가 표시될 수 있고, PRO 결제는 Google Play / RevenueCat을 사용합니다.
